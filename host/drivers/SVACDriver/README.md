# Steam Streaming Microphone

This directory contains Valve's signed x86 and x64 Steam Streaming Microphone
driver packages. Moonmic Host extracts the matching package and installs it from
Driver Manager.

After installation, select `Steam Streaming Microphone` as the recording input
in Discord, OBS, or another application. Moonmic disables the unused playback
endpoint to avoid selecting it accidentally.

The driver remains the property of Valve Corporation and retains its original
signature and catalog.
