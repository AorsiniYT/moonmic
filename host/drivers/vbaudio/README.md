# VB-CABLE

This directory contains the signed VB-CABLE driver files distributed by
VB-Audio Software. Moonmic Host embeds these files and installs the appropriate
package from Driver Manager or with `moonmic-host.exe --install-driver`.

Moonmic writes received audio to `CABLE Input`. Applications capture that audio
from `CABLE Output`.

VB-CABLE is donationware. See [VB-Audio's website](https://vb-audio.com/Cable/)
and `readme.txt` for its license and support information.
